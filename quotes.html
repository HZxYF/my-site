Quotes

Programs must be written for people to read, and only incidentally for machines to execute.

Harold Abelson and Gerald Jay Sussman

Fifteen lines I keep coming back to. All of them are about making things for other people to use, which is what this whole course is about. One is shown at random above; the full list is below.

  1. Programs must be written for people to read, and only incidentally for machines to execute.

    Harold Abelson and Gerald Jay Sussman, Structure and Interpretation of Computer Programs

  2. Simplicity is prerequisite for reliability.

    Edsger W. Dijkstra, 1975

  3. Premature optimization is the root of all evil.

    Donald Knuth, 1974 — who credits the idea to Tony Hoare

  4. Any fool can write code that a computer can understand. Good programmers write code that humans can understand.

    Martin Fowler, Refactoring

  5. Make it work, make it right, make it fast.

    Kent Beck

  6. The best way to predict the future is to invent it.

    Alan Kay, 1971

  7. Talk is cheap. Show me the code.

    Linus Torvalds, on the Linux kernel mailing list

  8. Debugging is twice as hard as writing the code in the first place. Therefore, if you write the code as cleverly as possible, you are, by definition, not smart enough to debug it.

    Brian Kernighan and P. J. Plauger, The Elements of Programming Style

  9. There are two ways of constructing a software design: one way is to make it so simple that there are obviously no deficiencies, and the other way is to make it so complicated that there are no obvious deficiencies.

    C. A. R. Hoare, Turing Award lecture, 1980

  10. Controlling complexity is the essence of computer programming.

    Brian Kernighan

  11. Design is not just what it looks like and feels like. Design is how it works.

    Steve Jobs, 2003

  12. The details are not the details. They make the design.

    Charles Eames

  13. Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away.

    Antoine de Saint-Exupéry, Terre des hommes, 1939

  14. Good design is as little design as possible.

    Dieter Rams

  15. A user interface is like a joke. If you have to explain it, it is not that good.

    Martin LeBlanc

Attributions were checked against Wikiquote. Where a line is widely credited to the wrong person, the note says so instead of repeating the mistake.
